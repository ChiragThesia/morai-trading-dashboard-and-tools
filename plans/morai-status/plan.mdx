# Morai — Project Status

**Online options-trading journal**: web UI + typed API + background jobs + MCP server, one system. Collects Schwab/CBOE data, keeps a per-calendar journal (30-min RTH snapshots of price / greeks / term-structure), computes derived analytics (skew, term-structure), and exposes all of it to the browser and to Claude Code.

**Where it stands (2026-06-22):** the backend is **feature-complete — Phases 1–7, all merged to `main`** — and **production is live again** (server + worker healthy on Railway, DB connected, Schwab tokens fresh). The last mile — pulling your real trade history — is mid-flight: the live trader API was erroring, now being fixed (PR #9 in CI).
