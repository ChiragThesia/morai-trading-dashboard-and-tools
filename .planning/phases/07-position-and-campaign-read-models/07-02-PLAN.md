<objective>
Phase goal (ROADMAP, verbatim): "Open/closed state, per-leg settlement, and rolled-position chains
are computed from events, with no second writer for anything derivable."

This plan closes ROADMAP criterion 1. A position's open/closed state becomes a pure function over
decrypted fills, every reader is moved off the stored timestamps, and only then does migration 0014
drop them — along with adding the roll link column and the campaign view the rest of the phase needs.

Purpose: calendar `65aac62e` reported open in v1 after its real close order had fully unwound both
legs, because a stored field had drifted from the fills. Phase 3 already declined to add a `status`
column for exactly this reason. `opened_at`/`closed_at` are that same column wearing a different
type, and keeping them while merely not writing them is weaker — the column still exists to disagree.

Output: `derive_position_state` in `positions.py`, every reader moved off the columns, and migration
0014 carrying all three schema changes as one revision (D7-15).

**Task ordering is deliberate and load-bearing.** The readers move off the columns *before* the
columns are dropped, so the suite is green after every task rather than red between two of them.
</objective>
