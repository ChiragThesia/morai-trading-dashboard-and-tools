<objective>
Phase goal (ROADMAP, verbatim): "Open/closed state, per-leg settlement, and rolled-position chains
are computed from events, with no second writer for anything derivable."

This plan closes ROADMAP criteria 2 and 3. A leg past its expiry generates a persisted SETTLEMENT
event from its own expiry, strike and root — no fill, no broker call — and a position holding a
PM-settled SPXW front alongside an AM-settled SPX back produces two settlement rows, each on its own
style and its own date.

Purpose: `D026` records the v1 bug this prevents — inferring AM/PM from "is this a third Friday" is
safe only while the code never sees SPXW, and a real SPXW third Friday then gets tagged AM. Reading
style from `legs.root` is what makes per-leg settlement true rather than per-position.

The dominant technical risk is not the style rule. It is the existing idempotency key: `sync_events`
dedupes on `(position_id, event_type, fill_ids_hash)`, a SETTLEMENT's hash is always NULL, and
`events` has no `leg_id` column — so two legs of one position produce an identical triple and the
second row is silently skipped on the very first sync. Broadening the key to include `event_time` is
the fix, and the mixed-style test must assert **two** rows, not one.

Output: `src/morai/ledger/settlements.py`, the fold into `sync_events`, and a test file whose
fixtures are labelled synthetic in the file itself (D7-13).
</objective>
