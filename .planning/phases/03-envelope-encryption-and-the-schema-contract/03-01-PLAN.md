<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app process → Postgres | Only ciphertext, nonces and the plaintext-by-design columns cross. No key ever does. |
| Postgres → a stolen dump or backup | The project's stated threat model target. The dump must be inert without the KEK. |
| environment → app process | The KEK arrives as an environment variable and is never rendered, logged or echoed. |
| caller code → the fill table | Every write must pass through `insert_fills`, where encryption happens. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Information Disclosure | `fills` price/quantity columns in a stolen dump | critical | mitigate | AES-256-GCM per column under a per-user DEK wrapped by an env-var KEK (ASVS 5.0 V11.3.1, V11.3.2; V14.1.1). Proof deferred to plan 03-03's real dump-and-restore test. |
| T-03-02 | Information Disclosure | KEK rendered in a configuration error message | high | mitigate | `master_key_bytes` raises outside any `except`, naming only the field, never the value (`NN-34`); asserted in `tests/test_settings.py`. |
| T-03-03 | Information Disclosure | Nonce reuse under one DEK collapsing GCM confidentiality | high | mitigate | Fresh `os.urandom(12)` inside every `encrypt_field` call, never per row or per user; freshness asserted in Task 2 and the stored-nonce invariant queried in plan 03-03 (ASVS 5.0 V11.3.4). |
| T-03-04 | Tampering | Ciphertext copied from one fill row into another | medium | mitigate | Associated-data binding to the row's own composite key, with the serialization fixed once and documented in the migration; wrong-row decryption asserted to raise in Task 2. |
| T-03-05 | Tampering | A second, unencrypted write path into `fills` | high | mitigate | Required write-token on the ORM constructor, proved by a `tests/gate/` fixture asserting a real checker's own marker (Task 3), plus a runtime guard (Task 2).
