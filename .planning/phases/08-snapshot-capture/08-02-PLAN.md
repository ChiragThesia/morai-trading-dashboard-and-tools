<objective>
ROADMAP criteria 2, 3 and 5, made true and proven: a slot with no market data stores an explicit
gap; a later real observation heals it; a real observation is never replaced by a gap; and a user
whose connection is expired gets an honest gap rather than a skipped row.

Purpose: the asymmetric upsert is the single highest-risk line in this phase. `D8-10` is deliberately
asymmetric and the asymmetry *is* the requirement. In v1 the wrong clause blocked the backfill of
1,190 corrupted contracts until it was flipped, and separately discarded a later, more complete
recompute in favour of an early partial one (`L020`, `L005`, `L071`). A test covering three cells of
the truth table passes while the one clause that matters is broken, so this plan tests all four
directly against Postgres.

Output: the three gap branches wired into `capture_user_snapshot`, the RTH-grid edge coverage, and
`tests/ingest/test_snapshot_gap_upsert.py` — the database-level guard tested as a database-level
guard.
</objective>

    - Key discrimination: two legs belonging to two different positions but carrying the identical `occ_symbol` produce two independent rows for the same slot. Keying on the symbol instead would collide them (`NN-1`, `L001`, `L002`).
    - The identical five-cell table holds for `snapshot_observations` as well as `snapshot_marks` — both writers carry the same clause, so both are asserted.
