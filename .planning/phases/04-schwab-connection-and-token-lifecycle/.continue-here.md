## The landmine that fails silently, carried forward

`schwab-py`'s `token_write_func` is **never awaited** — `schwab/auth.py`'s
`wrapped_token_write_func` is a plain `def` calling the closure with no `await` (verified in
the real 1.5.1 wheel). An `async def` closure returns a coroutine that is assigned, never
awaited, then dropped; Python emits only a GC-time RuntimeWarning. **OAuth returns 200 and
the token never persists.** 04-01 designed around it (sync capture into a holder, async
persist from the caller). Any new refresh-path code in 04-03 must follow the same shape —
the plan says so, and 04-03 Task 1 repeats the warning.
